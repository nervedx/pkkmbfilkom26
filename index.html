Panduan Video Perkenalan

Twibbon format video tidak dapat diedit secara otomatis melalui website ini. Silakan ikuti langkah berikut untuk mengeditnya menggunakan perangkat Anda:

  1. Unduh file mentahan (template) Twibbon Video yang telah disediakan panitia.
  2. Buka aplikasi edit video pilihan Anda (contoh: CapCut, VN, KineMaster, atau Premiere Pro).
  3. Masukkan video perkenalan diri Anda sebagai layer utama (video dasar).
  4. Tambahkan template Twibbon Video sebagai Overlay (lapisan di atas video Anda).
  5. Gunakan fitur Chroma Key (Kunci Kromatik) atau Blend Mode (Campuran) pada aplikasi tersebut untuk menghilangkan warna latar (hijau/hitam) pada twibbon.
  6. Sesuaikan letak video Anda agar pas berada di dalam bingkai, lalu Export/Simpan hasilnya.
